# Security Policy / 安全策略

## English

If you discover a security vulnerability, please **do not open a public issue**.

- Use GitHub's **private vulnerability reporting** on this repository, or
- Contact the maintainer privately: [@hx346](https://github.com/hx346)

Please include a description of the issue, reproduction steps, and potential impact. We will respond as soon as possible.

Note: if you deploy this system, keep LLM API keys (`AI_API_KEY`) and database credentials in environment variables or a secret manager — never commit them to the repository.

---

## 简体中文

如发现安全漏洞，请**不要公开 Issue**。

- 请使用本仓库的 GitHub **私密漏洞报告**功能，或
- 私信联系维护者：[@hx346](https://github.com/hx346)

请附上问题描述、复现步骤和潜在影响，我们会尽快响应。

提醒：部署本系统时，LLM API Key（`AI_API_KEY`）和数据库凭据请通过环境变量或密钥管理服务注入，切勿提交到仓库。
