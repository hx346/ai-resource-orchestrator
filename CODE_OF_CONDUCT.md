# Code of Conduct / 行为准则

## English

We are committed to providing a friendly, safe, and welcoming environment for everyone.

**Expected behavior:**

- Be kind, respectful, and constructive in discussions.
- Assume good faith and focus on technical merit.
- Accept constructive criticism and differing viewpoints.
- Keep discussions on topic and professional.

**Unacceptable behavior:**

- Harassment, personal attacks, or discriminatory language.
- Trolling, insulting, or derogatory comments.
- Publishing others' private information without consent.
- Any conduct reasonably considered inappropriate in a professional setting.

**Enforcement:**

Violations may be reported to the maintainers via a private GitHub message to [@hx346](https://github.com/hx346) or by opening a private security advisory. Maintainers may remove, edit, or reject comments, commits, code, issues, and PRs that violate this code of conduct.

---

## 简体中文

我们致力于为所有人提供友好、安全和受欢迎的环境。

**期望的行为：**

- 在讨论中保持友善、尊重和建设性。
- 假定善意，聚焦技术本身。
- 接受建设性批评和不同观点。
- 讨论保持切题和专业。

**不可接受的行为：**

- 骚扰、人身攻击或歧视性言论。
- 恶意挑衅、侮辱或贬损性评论。
- 未经同意公开他人隐私信息。
- 在专业场合中被合理认定为不当的任何行为。

**执行：**

违规行为可通过 GitHub 私信 [@hx346](https://github.com/hx346) 私密举报给维护者。维护者有权删除、编辑或拒绝违反本准则的评论、提交、代码、Issue 和 PR。
